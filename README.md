# ODDS LENS LIVE

배트맨 프로토 승부식의 현재 회차 배당·배당 변경 이력·구매 건수를 10분마다 자동으로 받아와서, ODDS LENS 모델로 판정해 보여주는 페이지.

- 페이지: https://minhu8238.github.io/odds-lens/
- 자동 수집: `.github/workflows/scrape.yml` (10분마다, Actions 탭에서 수동 실행 가능)
- 데이터: `data/latest.json` (현재 회차), `data/hist/<회차>.json` (경기별 시간대 기록: 배당이 바뀌거나 60분마다 [분 단위 시각, 배당3, 구매건수3])

판정 기준: 축구 일반 후보만 실전 검증 통과(2024년 이후 ROI −6.3%, 아무거나 −15.5%). 피하기는 6개 시장 검증. 어떤 등급도 기대 ROI는 마이너스.

## 자동 분석
- `scripts/analyze.js`: 수집할 때마다 경기별로 모델 판정과 과거 비슷한 경기 3단계(① 최종만 ±1%p ② ATLAS: 초기·최종 ±2%p(2way 1.5)·움직임 방향·변경 여부 일치 ③ ATLAS+구매율 ±10%p(2way 7)), 같은 시장·기준점, 표본 수와 함께 모두 표시
- `data/history/*.csv.gz`: 2013~2026.11 배트맨 과거 데이터 약 35만 경기 (날짜, 최종배당, 초기배당, 구매율, 변경횟수, 기준점, 결과칸)
- `data/history_new/<회차>/*.csv`: 수집기가 끝난 경기를 회차별로 자동 추가. 분석할 때는 분석 회차보다 앞선 회차(직전 회차까지)만 사용

## 일반+핸디캡 짝 비교 (메인 판정)
- `data/history/pair_<종목>.csv.gz`: 같은 경기의 일반+핸디캡 짝 과거 데이터 (date,w,d,l,ch,vw,vd,vl,line,hw,hd,hl,hch,hvw,hvd,hvl,res,hres)
- 비교 조건: 일반 최종배당 확률·배당 변경 유무·구매율 + 핸디 기준점(같음)·최종배당 확률·변경 유무·구매율
- 좁게: 배당 ±2%p, 구매율 ±10%p. 10경기 미만이면 넓게: ±3%p, ±15%p
- 끝난 경기는 `data/history_new/<회차>/pair_<종목>.csv`에 자동 추가, 직전 회차까지만 비교에 사용
